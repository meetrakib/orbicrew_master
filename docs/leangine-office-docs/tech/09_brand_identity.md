**This document is global, US/EU-first, English-only, full stop.** Brand truth: a premium AI employee platform — cost-transparent, "your AI office, not another chatbot" — for solo agencies, freelancers, and small teams anywhere English is a working business language, primarily the US and Europe. It does not require a named font, a design choice, or a mention in a brand document, and none appears below. Bangla is retained in this document in exactly one place — Section 1.3, a short list of Bangla-rooted words usable only as a brand *name* if you want one, per your explicit instruction — and nowhere else.

## 4. Logo, mark, and voice

**Logo direction:** a wordmark-led approach (not icon-led), set in the chosen display face, in the primary brand color, using the chosen name as the single primary mark — no non-English companion mark, since the brand is one visual system everywhere regardless of what language a given customer's chat conversations render in. Avoid a literal robot/gear/circuit icon (extremely common in AI-product logos, works against distinctiveness) and avoid the current wave of soft-gradient-blob or generic neuron/spark icons that read as "obviously AI-generated branding" rather than deliberately designed. If a mark is wanted alongside the wordmark, an abstract desk/seat motif at extreme simplification (a single geometric shape suggesting a chair-at-a-desk from above) ties to the office metaphor without being literal.

**Voice & tone principles:**

- **Plain verbs, no hype.** Name things by what people control, not how the system works internally. "3 agents working," not "3 autonomous workflow instances active."
- **Cost-honest language everywhere.** Show real task counts and real dollar amounts, never a vague "credits" abstraction — this is the core differentiator vs. competitors' opaque systems, and the product's own copy should model it.
- **Global English, no region-specific idiom.** Copy reads naturally to a buyer in the US or anywhere in Europe — avoid idioms or spelling conventions tied to one specific English-speaking region where a neutral phrasing exists.
- **Multilingual chat, not multilingual brand voice.** People can converse with their agents in any language they choose (a product capability, covered in `10_ui_ux_guide.md`), but the brand's own copy — marketing site, UI chrome, emails, everything the company itself writes — stays English. This is a different thing from the chat feature and should never be conflated with it.
- **Premium through restraint, not decoration.** Minimal, elegant, modern, premium, and specifically not "AI-generated" in feel — no excessive gradients, no stock glowing-orb AI imagery, no exclamation-heavy copy, generous whitespace over dense information, confidence expressed through what's left out rather than what's added.

**Usage discipline:** violet (`--accent-primary`) is the dominant identity color — wordmark, primary CTAs, active states, links. Gold (`--accent-gold`) is a genuine accent, meaning it appears sparingly — a badge, a small highlight, a single emphasized number — never as a large background fill or a second competing "primary" color. Two dominant colors fighting for attention reads as indecisive; one primary plus one restrained accent reads as designed.

### 6.4 Typography — locked

Carried forward unchanged from Section 2, Option 3 (the document's original top typography recommendation): **Bricolage Grotesque** (display/heading, 600 weight) + **Hanken Grotesk** (body, 400 weight). This pairing was chosen specifically because it avoids the Inter+Inter or Space Grotesk+Inter combination that the overwhelming majority of AI-SaaS products default to (both Lindy and Manus lean on plain, safe system-sans treatments) — Bricolage Grotesque's slightly imperfect, contemporary display character gives Orbicrew's wordmark a distinctive silhouette at a glance, while Hanken Grotesk keeps body copy and dashboard UI highly legible. See Section 7 below for the full type scale and usage rules.

### 6.5 Logo — locked

Three-tier lockup system, wordmark-led (not icon-led), matching the pattern both Lindy and Manus use (their icons exist only as small-format fallbacks, never the primary mark):

**Primary — wordmark only.** "Orbicrew" set in Bricolage Grotesque, 600 weight, in `--accent-primary` (violet). This is the default, used everywhere a size larger than roughly 160px width is available: website header, marketing pages, dashboard chrome, email signature, social profiles, press materials, pitch decks. No icon accompanies it in this form — the name carries the brand alone.

**Secondary — icon + wordmark, horizontal lockup.** The compact icon (defined below) placed to the left of the wordmark, vertically centered, with a fixed gap between them (icon height sets the gap: gap = 0.4× icon height). Used in compact horizontal spaces where the wordmark alone would be too wide relative to available height but there's still room for both — app top-nav bars, in-product headers, button labels that need a brand anchor, browser bookmark bars.

**Compact icon — favicon / app icon only, 32-48px contexts.** A circular "orb" motif with the letter "O" integrated as the outer ring, built from the same orbiting-rings concept as the naming metaphor: a violet ring (the "O" of Orbicrew) with a smaller solid violet core dot slightly offset toward the top, and one small gold satellite dot near the ring's upper edge — reading simultaneously as the letter O and as a simplified orbit diagram. Rendered on a rounded-square tile using `--bg-primary` (light lavender) as the tile background in light mode, `--bg-surface` dark-mode value as the tile background in dark mode. This mark never appears alone above roughly 64px — past that size, use the secondary lockup (icon + wordmark) or the primary wordmark instead, since the icon is deliberately simple enough to read at tiny sizes and starts to look under-designed if scaled up as a standalone mark.

**Explicitly avoided:** no robot/gear/circuit icon (extremely common in AI-product logos, actively hurts distinctiveness). No soft-gradient-blob or generic neuron/spark icon (reads as "obviously AI-generated branding"). No tagline baked into the lockup — "Orbicrew" alone is the mark; "by Leangine" or any tagline is separate copy, set in body type near the mark, never part of the logo file itself.

**File deliverables:**

| Lockup | Format | Minimum size | Notes |
|---|---|---|---|
| Primary wordmark | SVG + PNG (transparent) | 160px width | Default for nearly all uses |
| Secondary (icon + wordmark) | SVG + PNG (transparent) | 240px width | Icon stays 1:1 square within the lockup |
| Compact icon | SVG, PNG, ICO | 32-64px | Favicon and app-icon contexts only |
| Color | — | — | Violet `#534AB7` (primary), Gold `#E0A94C` (accent, sparingly) |

### 6.6 Voice — unchanged

Carried forward from Section 4 without modification: plain verbs, no hype; cost-honest language everywhere (real numbers, never vague "credits"); global English, no region-specific idiom; premium through restraint, not decoration.
